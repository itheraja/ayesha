# Demo doctor directory

Updated 24 October 2026. The default catalogue contains 54 specialties and 162 fictional doctors, with three doctors per specialty across campuses (not three at each campus). This broad catalogue does not claim to include every rare subspecialty or represent actual hospital staffing or service availability.

Existing doctor IDs and appointments are preserved. New doctors receive fourteen days of demonstration slots. Reseeding is additive and does not reset bookings. Common specialist names, English descriptions and selected Urdu/Roman Urdu aliases are supported. Exact specialty searches keep adult and paediatric subspecialties separate.
